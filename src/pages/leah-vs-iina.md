# Leah vs IINA

Leah and IINA are both video players made for the Mac. IINA is free, open source and built on the mpv player, with many settings and plugins. Leah is a paid Mac App Store app built on Apple's own video frameworks, made to be simple and to seek instantly.

## At a glance

| | Leah | IINA |
|---|---|---|
| Price | $9.99, once | Free |
| Source code | Closed | Open source (GPLv3) |
| Where to get it | Mac App Store | iina.io |
| Macs | Apple silicon, macOS 15 or later | Apple silicon with macOS 12 or later, Intel with macOS 11 or later |
| Built on | Apple's AVFoundation and VideoToolbox, with Leah's own MKV, TrueHD and DTS decoding | mpv |
| MKV and WebM | Yes | Yes |
| Blu-ray PGS and DVD VobSub subtitles | Yes | Yes |
| Dolby TrueHD | Up to 7.1, exactly as recorded | Yes |
| Formats beyond Leah's list, such as Vorbis, VP8 and Xvid | No | Yes |
| Timeline preview | Yes | Yes |
| Picture in Picture | No | Yes |
| Plugins | No | Yes |
| Settings and customization | Few, by design | Many |
| Internet access | Never connects | Optional online features |
| Tracking | None | None |
| Languages | English | Many |

## Choose Leah if

- You want seeking and scrubbing that keep up with you: skip, drag along the timeline or jump anywhere, and the picture follows.
- You want a simple player with few settings that works the same way every time.
- You want an app from the Mac App Store that never connects to the internet.
- You play Blu-ray rips and want lossless Dolby TrueHD in up to 7.1 channels and PGS subtitles.

## Choose IINA if

- You want a free, open-source player.
- You have an Intel Mac, or a Mac with a macOS version older than 15.
- You need Picture in Picture, plugins, or many settings for the interface and playback.
- You play formats outside Leah's list, such as Vorbis audio or Xvid video.

## Formats

Leah plays MP4, MOV and M4V, and MKV and WebM files with H.264, HEVC, MPEG-2, MPEG-1, VP9 and AV1 video, Dolby TrueHD, Dolby Digital, Dolby Digital Plus, DTS, AAC, FLAC, Opus, Apple Lossless, PCM, MP3 and MP2 audio, and SRT, ASS/SSA, WebVTT, PGS and VobSub subtitles. See [Formats Leah plays](formats) for the details, such as which Macs play VP9 and AV1.

IINA plays the formats mpv supports, which is a wider list.
